            Compatibility, installation and reference selection
            Reference selection
            Matching uses the clip name and hash, skeleton identity, named leg component and channel mask. Compatible duplicate references are tried rather than silently taking the last file. Approved references have priority. Unmarked approved fixes default to final-space legs, as in the arms-safe venjmplnd correction; select native beta-space explicitly for an unmarked native-beta reference. Valid repair/conversion markers take precedence over this manual setting. Their motion is copied exactly when frame count, scene flag and quantization match; otherwise it is retimed and re-encoded.
            Conversion retains the source frame count, duration, names and flags, and writes the target character version: final 0x10003 or beta 0x10002. Only the leg motion is replaced or transformed; upper-body, arm, finger and tentacle motion stays original. The separate legacy repair keeps the beta version unchanged.
            Other characters
            Add the character’s beta .xbskel / .ps2skel and final .pcskel to identify component types and slots. If a map, compatible mask or safe reference is missing, the clip is reported and left unchanged. Generic 0x10200 records use their own serializer, preserving compressed curves, events and trajectories while adapting state/cache sizes and alignment. Companion mode converts their matching skeleton bytecode and pose storage too. Retail nalPed 0x500 is expanded into 21 explicit bone transforms plus trajectory in a real generic 0x10200 stream. Its original compact source is retained in a checksummed recovery trailer for exact conversion back to PC nalPed. Compact-pedestrian intermediate blends and gameplay behavior remain unverified.
            Experimental geometry and runtime
            The conversion fallback uses the source character’s animated pelvis, or a validated default pelvis, to transform foot-target rotations and positions. The inverse transform supports native-beta output. This is not an exact reconstruction of missing reference animation. Disable it to require compatible references. The separate legacy fallback remains Venom-only.
            Native Xbox beta writes beta-space legs. PC mod loader writes final-space corrected legs in a beta-version file, matching the earlier repair workflow. These conventions are not interchangeable.
            Install with the matching target runtime
            Back up your active mod. Rename the exported bank or raw clip to the resource filename your loader expects, then place it in your usual override folder. Move conflicting older overrides out of that folder. Do not also install final-PC reference files as donors if an older runtime merger would reprocess the fixed bank.
            The larger output is intentional. Do not force replacement streams back into the old compressed storage. Use the emitted target companion skeletons, or validated paired target rigs. Companion rigs are grouped per bank to avoid silently overwriting conflicting identities. They preserve source bone numbers; mesh remapping and compatibility with other stock banks are not provided. Do not mix the two beta-runtime modes. Test in-game, especially geometric corrections.
            Safety limits: 128 MiB per file, 192 MiB per browser batch, 100,000 decoded frames per clip (empty sentinels are retained without decoding), 2 million decoded values per component, 256 MiB per output/archive. Unrecognized or malformed files are reported. Original uploads remain local.
