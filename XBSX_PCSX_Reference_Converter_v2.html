        Restore the exact original from a recovery report
        This is separate from PCSX → XBSX conversion. A generated JSON report stores the original source bytes. Recovery checks the converted and original SHA-256 hashes before exporting.
        

        What this version reads
        The unlinked, little-endian generic-mash layouts found in the supplied Xbox and PC archives: multi-object scripts, initializer functions, permanent strings, static data, branches, event references and array instructions. Unknown or malformed layouts are rejected.
        What it does not invent
        No manual identifier table, arithmetic ID extrapolation, target-script replacement or missing game-code implementation. Contradictory candidates stay unresolved. Keep the reports and test copies before installing scripts.
